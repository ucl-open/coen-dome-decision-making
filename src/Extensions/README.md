# Local Bonsai extensions

Bonsai compiles every `*.cs` file here when `src\main.bonsai` loads, as C# 5 (`src\Extensions.csproj` sets `LangVersion` 5): no `$"..."`, `?.`, `nameof`, expression-bodied members or property initialisers. `tests\Extensions.Tests` (MSTest, net472, C# 5) tests them; `scripts\check-workflow.ps1` compiles and runs both. Everything shared between dome workflows lives in lib-open-rigs (see the README's Shared Blocks); only this task's logic is here.

| File | What it holds |
|---|---|
| `TrialLogic.cs` | `Trial` (lib-open-rigs' `IZapitTrial`, for its `ZapitTrialCommand`); `DrawTrial` and its tested core `TrialDraw` (trial types by the stage's weights, repeats by its rules, stimuli, rig.yml's nearest speaker, the Zapit condition, each trial's own interval, lead and quiet waits; refuses a stage past the table, empty contrasts, a side with no azimuth, location or speaker, and the timing rules: `laserToStimulusSeconds` + 0.2 s within `itiMinSeconds` and no later than the response window, `itiMinSeconds` at least `drinkSeconds`, the quiet waits, and with optogenetics `laserDurationSeconds` at most `openLoopSeconds` + `itiMinSeconds` - 0.5 s ramp-down - 0.2 s); `CheckTaskAtGo` (`TrialDraw.CheckTask` at Go, before the first trial); `StartTrials` (after lib-open-rigs' `OnNextTick`: the first draw from the Harp clock's thread), `EndTrial` (the loop: a trial ends at the start of the next interval); `TrialStartWaiter` and `WaitForTrialStart` (each trial's start on the Harp clock, on lib-open-rigs' OpenRigs.Core `QuietWait`: the interval's end less the lead, or later until the quiet waits hold; `startTime`, `quietWaitSeconds`); `SecondsUntil` (the seconds to a trial's stimulus or trigger from the trial start, for a `HarpDelay`; a moment already past stops the workflow); `TrialStartFor` (a trial's own start from the replaying `TrialStart`); `Consequence`/`TrialConsequence` (reward, spouts, penalty sound, timeout from the trial's row); `SpoutsIn`; `CheckZapitArmed`, `RequireZapitArmed` (the trigger passes only once Zapit has armed the trial), `UnlessAnswered` (no laser on a trial answered before its trigger) |
| `TrialRow.cs` | `TrialRow`, one `BonsaiData_Trial` row, its fields the columns of `schemas\trial-columns.yml` in order (a test holds them equal), and `CreateTrialRow` |
| `AuditoryStimulusSet.cs` | The stimulus set, each waveform equalised for each speaker by its filter, set at Go to the task's `audioStimulus.levelDbfs` (`LevelAuditoryStimulusSet`, every equalised copy's peak checked under -1 dBFS), and a trial's mixer buffer with its sync copy (`SelectAuditoryStimulus`, OpenRigs.Audio `SpeakerSet.Layout`); refuses a speaker with no filter, a filter from another machine or rate, and any missing or malformed file, naming it |
| `*.Generated.cs` | Bonsai.Sgen 0.9.0 classes for the task file (rig.yml's are OpenRigs.Devices' `OpenRigs.Devices.Rigs`); regenerate with `uv run regenerate-schemas`, never edit |
